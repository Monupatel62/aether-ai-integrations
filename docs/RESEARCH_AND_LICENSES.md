# Research and Licenses — aether-ai-integrations

## Evaluation areas
- Official provider APIs and sandbox environments.
- OAuth/OIDC scope granularity, refresh/revocation semantics, webhook signing, and rate limits.
- SDK maintenance, data processing terms, residency, and dependency posture.

## Review requirements
Before adoption, record provider API/version, terms, SDK license, scopes, data exchanged, outbound domains, rate limits, security advisories, and credential storage plan. Do not scrape or reuse provider content outside permitted terms.
